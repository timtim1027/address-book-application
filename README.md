# address-book-application

A simple Address Book Application developed using Angular and TypeScript.  
This project demonstrates CRUD operations (Create, Read, Update, Delete) with contact management functionality.

## Features
- Add new contacts
- Edit existing contacts
- Delete contacts
- Search contacts
- Form input validation
- User-friendly interface

## Technologies Used
- Angular
- TypeScript
- HTML
- CSS

## Project Purpose
This project was developed to practice frontend web development concepts, including:
- Component-based development
- Form handling and validation
- CRUD functionality
- Dynamic data rendering
- User interaction handling
